## Projects

### Airbnb Porto - Accommodation Pricing Analysis
> *What drives the price of a night in Porto?*

A full data science pipeline applied to Airbnb listings in Porto. This project explores the factors that influence short-term rental prices - from neighbourhood and property type to host behaviour and amenity bundles.

**It contains:**
- Exploratory Data Analysis (EDA) with `pandas` and `seaborn`
- Geospatial visualisation of listings across Porto's neighbourhoods
- Predictive pricing model using regression techniques (`scikit-learn`)
- Feature importance analysis - what actually moves the needle on price?

**Key question answered:** *Can we predict the nightly price of an Airbnb in Porto based on its (available) characteristics?*
